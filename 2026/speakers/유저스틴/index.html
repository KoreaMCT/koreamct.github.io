About

Microsoft에서 Principal Developer Advocate로 일하고 있습니다. 자나깨나 개발자 생산성 향상을 위한 도구들을 찾거나 만들거나 공유합니다.

발표 주제

Microsoft Agent Framework 및 Microsoft Foundry 기반 엔터프라이즈형 에이전틱 앱의 개발 및 배포를 손쉽게 할 수 있는 스타터 팩 소개

지금까지 Microsoft Agent Framework(MAF) 또는 Microsoft Foundry 서비스를 소개하는 샘플 코드는 주로 Hello World 수준이었습니다. 이번에 Microsoft CoreAI 조직에서 제공하는 스타터 팩을 활용하면 MAF와 파운드리, MCP 서버 등을 Aspire로 오케스트레이션한 후 Azure Container Apps(ACA)로 한방에 배포할 수 있습니다. 이 세션에서는 MAF 및 파운드리 에이전트 서비스에 대해 소개하고 스타터 팩 적용 방법과 멀티 에이전트 오케스트레이션 패턴 구현 방법을 알아봅니다.
